# Modèles

Ce dossier contient des **modèles prêts à copier** : il n'est jamais publié sur
le site (les dossiers dont le nom commence par « _ » sont ignorés).

| Modèle | À copier dans | Mode d'emploi |
|---|---|---|
| `logement/` (avec son dossier `photos`) | `content/logements/` | docs/10-ajouter-un-logement.md |
| `etablissement/` (une adresse) | `content/etablissements/` | docs/11-ajouter-une-adresse.md |
| `destination/` (nouvelle ville) | `content/destinations/` | docs/11, fin |
| `avis.md`, `guide.md`, `page.md` | `content/avis/`, `content/guides-locaux/`, `content/pages/` | docs/02 |

Nommage : le dossier d'un logement = le dossier de son adresse + une précision,
même s'il est seul (`le-47-studio`, `le-37-studio`, `13-rue-de-la-paille-studio-1`).

Le workflow **Créer un logement** (onglet Actions) fait la copie à votre place.
