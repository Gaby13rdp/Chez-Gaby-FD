# Modèles

Ce dossier contient des **modèles à copier** : il n'est jamais publié sur le site
(les dossiers dont le nom commence par « _ » sont ignorés).

- `logement/` : utilisé par le workflow **Créer un logement** (ou à copier à la main).
- `etablissement/`, `destination/` : créés automatiquement si besoin par le même workflow.
- `avis.md`, `guide.md`, `page.md` : à copier dans le bon dossier puis compléter.

Mode d'emploi : `docs/02-utilisation-quotidienne.md`.
